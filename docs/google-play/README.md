# Google Play listing assets

- `icon-512.png`: store listing app icon (512 × 512).
- `feature-graphic-1024x500.png`: store listing feature graphic (1024 × 500).
- `screenshots/`: full-resolution portrait screenshots (1080 × 1920), ready to upload to Play Console.

The README showcase uses matching copies from `docs/ui/`. All artwork was supplied for this project; the original captures are kept at their full resolution without cropping or upscaling.
