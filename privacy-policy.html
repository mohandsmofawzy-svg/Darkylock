Privacy Policy for Darkylock

Application: Darkylock
Developer: Mohamed Mahmoud
100% On-Device Privacy Guaranteed

Thank you for choosing Darkylock. Your privacy and data security are fundamental to our mission. This Privacy Policy details our principles and practices regarding data handling, permissions, and security when you use our application.

1. Zero Personal Data Collection

Darkylock is designed with privacy-first architecture. We do not collect, transmit, store, or share any personal, sensitive, or diagnostic data from your device. All operations, configuration settings, cellular signal analyses, and performance optimizations are processed strictly locally on your device.

  • No analytics or tracking SDKs are integrated into Darkylock.
  • No user accounts, login credentials, or identity information are required or collected.
  • No personal identifiers, device identifiers, or telemetry are transmitted to external servers.

2. Android Permissions and Purpose of Use

Darkylock requests specific Android permissions strictly to deliver its core network lock and performance optimization features. Below is a detailed breakdown of permissions and their purposes:

Permission Required For / Core Purpose Data Handling
android.permission.READ_PHONE_STATE Reads SIM slot status and active subscription mapping to match modem interfaces on multi-SIM devices. Processed strictly in memory on-device. Never stored or shared.
android.permission.ACCESS_FINE_LOCATION
android.permission.ACCESS_COARSE_LOCATION		 Required by Android Telephony APIs (TelephonyManager.getAllCellInfo) to scan and display current cell PCI, ARFCN, and signal metrics. Used solely for displaying live cellular metrics to the user. Location data is never recorded, tracked, or sent anywhere.
android.permission.POST_NOTIFICATIONS Displays ongoing status notifications when network band locks, cell locks, or Drop-Fix service are actively running. Notification status is local to the device UI.
android.permission.FOREGROUND_SERVICE
FOREGROUND_SERVICE_SPECIAL_USE		 Runs the DropFixService in the foreground to keep user-requested Android game performance mode active during gameplay. Local background thread execution. No background data collection.

3. Elevated Privileges (Root & Shizuku)

Darkylock provides optional advanced functionality utilizing Root or Shizuku elevated access for interacting with system modem controllers (Qualcomm, MediaTek, Samsung, Pixel) and native game performance modes:

  • Local Scope Only: Commands executed via Root or Shizuku run strictly on your local device to communicate with hardware interfaces (e.g., QRTR sockets, AT commands, or system game mode settings).
  • No Data Export: Elevated access is never used to read, inspect, or transfer user files, personal data, or private app information.
  • User Control: Access must be explicitly granted and can be revoked by the user at any time through Root manager (Magisk/KernelSU/APatch) or the Shizuku manager app.

4. Data Storage & Security

Any app preferences (such as selected favorite bands or language choice) are stored locally in private application storage via Android SharedPreferences. This data remains on your physical device, is isolated from other apps, and is automatically cleared if you uninstall the application.

5. External Services and Third-Party Links

Darkylock does not contain third-party ad networks, tracking services, or commercial SDKs. The app may include an optional manual release update checker that queries public GitHub API endpoints. If enabled, this check retrieves only public release version numbers and does not transmit any user data.

6. Children's Privacy

Darkylock is a general utility application intended for mobile network configuration and performance optimization. It does not target children under the age of 13 and does not knowingly collect data from children.

7. Changes to This Privacy Policy

We may update our Privacy Policy periodically to reflect app updates or regulatory requirements. Any changes will be posted on this page with an updated effective date.
